# Zion Trybe — God's Dwelling Place

The official website for **Zion Trybe Lagos**, a Spirit-filled church family in Fadeyi, Lagos, Nigeria —
*a place where FAITH meets FAMILY.*

- **Lead Pastor:** Yomi Hassan
- **Co-Pastor:** Tosin Yomi Hassan
- **Service:** Sundays, 8:30am WAT
- **Location:** 20 Adewusi Street, Fadeyi, Ikorodu Road, Lagos, Nigeria

## About this site

A mobile-first, fully responsive static website built with HTML, CSS and vanilla JavaScript.
The design uses the brand colours drawn from the Zion Trybe logo — charcoal black with a fiery
red-to-orange "flame" accent.

### Features
- Looping video hero (landing) with a sound toggle
- Photo gallery (worship, services & family) with a lightbox
- Pages: Home, About, Sermons, Ministries, Events, Gallery, Plan a Visit, Give, Find Help, Beliefs, Contact
- Logo favicon in the browser tab

### Things to personalise
A few placeholders are clearly marked in the code for the church to update:
- WhatsApp number (`index.html` / `includes/footer.html`)
- Bank/giving account details (`give.html`)
- YouTube sermon video IDs (`sermons.html`, `index.html`)
- Social media handles, if different

## Local preview
Open `index.html` in a browser, or run a static server:

```bash
python -m http.server 8000
```

Then visit http://localhost:8000
